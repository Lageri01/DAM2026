We combined both the embarked and disembarked csv-files into one csv-file with R.

First we look at the amount of ships and the amount of captives they had when they embarked.

Now we look at the amount of captives who perished during the voyage

We can make a simple equation that involves taking the amount of embarked captives and subtracting it from the amount of disembarked captives.

\[ \text{Perished captives}=\text{Embarked captives}-\text{Disembarked captives} \] Latsly, we can find how big a percentage the perished made out of the embarked captives with the following equation.

\[ \text{Mortality rate percentage}=\frac{\text{Perished captives}}{\text{Embarked captives}}\cdot100 \]

The bodies of the captives who perished were most likely thrown in the ocean which would explain why the amount of disembarked captives was lower.

Captives_data <- Captives_data %>%
  mutate(
    Perished = All_Embarked - All_Disembarked,
    Overall_mortality_rate_percentage = round((Perished / All_Embarked) * 100, 2))

Average_overall_mortality_percentage <- Captives_data %>%
  summarize(Average_mortality_percentage = mean(Overall_mortality_rate_percentage, na.rm = TRUE))

The total amount of captives who perished was 1.447.693 or 1.45 million. The average mortality rate percentage was 17.0443243% across all voyages throughout the period.

To create a stacked bar chart we need to separate the entire bar for one \(x\)-value into their own respective values.

i.e. we need to separate the values for the amount of captives who survived and how many perished.

Perished_stacked <- Captives_data %>%
  slice(1:36) %>%   # Choose the first 37 rows
  mutate(
    Perished = All_Embarked - All_Disembarked,
    Mortality_rate_percentage = if_else(
      All_Embarked == 0,
      0,
      Perished / All_Embarked * 100)
    ) %>% 
  transmute(        
    `Year range`,
    Survived = All_Disembarked,  # We define survived and perished
    Perished = Perished
  ) %>%
  tidyr::pivot_longer(            # pivot_longer is used to increase the number of rows and decrease the number of columns.
    cols = c(Survived, Perished), # # We create two columns
    names_to = "Status",
    values_to = "Captives"
  )

# Prepare data for faceted plot
Facet_data <- bind_rows(
  Perished_stacked %>%
    mutate(Panel = "Outcome of embarked captives"),

  Perished_stacked %>%
    filter(Status == "Perished") %>%

Mortality_percentage_plot

Although the absolute number of deaths increased during periods of peak slave-trading activity, the mortality rate generally declined over time. This indicates that a smaller proportion of embarked captives died during the Middle Passage, even as the total number transported—and consequently the total number who perished—remained extremely high.

However, one thing that cannot be deducted from the plots is that even though the mortality rate was lowered, that does not mean the conditions onboard the ship were better. We know from sources, that the captives were packed very tightly in cramped spaces to maximize the amount of natives, which could be transported. (https://cdn.britannica.com/07/182907-050-C67CF42C/Detail-slave-ship-British-broadside-manner-children.jpg)

# Chosen countries we want to examine
Chosen_countries <- c(
  "Portugal / Brazil",
  "Great Britain",
  "France",
  "Spain / Uruguay"
)

# Creating a country dataset
Country_data <- Captives_data %>%
  slice(1:36) %>%
  select(
    `Year range`,
    matches("_Embarked$|_Disembarked$")
  ) %>%
  select(-starts_with("All")) %>%
  pivot_longer(
    -`Year range`,
    names_to = c("Country", ".value"),
    names_pattern =
      "(.*)_(Embarked|Disembarked)"
  ) %>%
  
  filter(
    Country %in% Chosen_countries
  ) %>%
  
  mutate(
  Perished = Embarked - Disembarked,

  Mortality_rate_percentage =
    replace(
      Perished / Embarked * 100,
      is.nan(Perished / Embarked * 100),
      0
    )
)

# Preparing the facet data
Facet_plot_countries <- bind_rows(

  # Outcome plot
  Country_data %>%
    select(
      `Year range`,
      Country,
      Survived = Disembarked,
      Perished
    ) %>%
    pivot_longer(
      cols = c(Survived, Perished),
      names_to = "Status",
      values_to = "Value"
    ) %>%
    mutate(
      Panel = "Outcome of embarked captives"
    ),

  # Perished captives
  Country_data %>%
    transmute(
      `Year range`,
      Country,
      Status = "Perished",
      Value = Perished,
      Panel = "Perished captives"
    ),

  # Mortality rate
  Country_data %>%
    transmute(
      `Year range`,
      Country,
      Status = "Mortality rate",
      Value = Mortality_rate_percentage,
      Panel = "Mortality rate percentage"
    )
)


abolition_lines <- abolition_years %>%
  
  mutate(
    
    Year_range_position = sapply(
      abolished_slavery_year,
      function(year) {
        
        unique(Facet_plot_countries$`Year range`)[
          sapply(
            strsplit(unique(Facet_plot_countries$`Year range`), "-"),
            function(rng) {
              
              lower <- as.numeric(rng[1])
              upper <- as.numeric(rng[2])
              
              year >= lower & year <= upper
            }
          )
        ]
      }
    ),

    x_position =
      match(
        Year_range_position,
        unique(Facet_plot_countries$`Year range`)
      ),

    label = paste0(
      "Abolished\n",
      abolished_slavery_year
    )
  )
